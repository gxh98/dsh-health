# DSH-昊哥健康管理

一个手机端优先的喝水与运动记录小站。打开就能用，不需要登录。

**在线使用：** https://gxh98.github.io/dsh-health/

## 解决什么问题

想随手记一杯水、一次运动，又不想为了打卡下载 App 或注册账号。这个页面把饮水和运动记录放在同一屏，数据只留在当前设备的浏览器里。

## 主要功能

- 饮水：点一次记录 250 ml；今日合计、2,000 ml 目标圆环、完成百分比、还差多少实时更新；记录可逐条撤销。
- 运动：跑步、散步、骑行、拉伸、瑜伽；跑步 / 散步 / 骑行记公里 + 分钟，拉伸 / 瑜伽只记分钟；只显示有记录的项目；跑步显示每次配速和今日平均配速。
- 今日记录卡：生成一张 PNG，包含头像、昵称、日期、饮水完成情况和运动汇总；桌面可下载，手机可长按保存。
- 昵称：点昵称旁的“编辑”修改；昵称和记录保存在当前浏览器，刷新不丢。
- 无登录、无后端、无第三方统计。

## 打开方式

- 在线：打开 https://gxh98.github.io/dsh-health/
- 本地：直接用 Chrome / Edge 打开 `index.html`。

## 使用方法

1. 点“喝一杯”记录 250 ml 饮水。
2. 选择运动项目，填写距离 / 时长，点“记录”；记录会出现在下方。
3. 点“生成今日记录卡”，保存图片分享。
4. 点昵称旁的“编辑”修改昵称。

## 隐私说明

- 本页面不收集、不上传任何个人数据；没有后端、统计或追踪。
- 昵称、饮水与运动记录只存在于当前浏览器的 localStorage。
- 清理浏览器数据会删除记录；换设备不会同步。
- 页面加了 `noindex` 标记，默认不希望被搜索引擎收录。
- 在内嵌沙盒预览（如聊天窗口内的网页预览）中，浏览器会禁止本地存储；请用真实浏览器打开。

## 已知限制

- 数据不跨设备同步。
- 饮水目标固定为 2,000 ml，单次固定 250 ml。
- 本页面只用于日常记录，不构成医疗建议。
